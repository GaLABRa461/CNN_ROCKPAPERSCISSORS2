
# Rock, paper, scissors: Construccion de un modelo cnn. 
Este archivo contiene información de imágenes del famoso juego piedra, papel o tijera. Encontraras el desarrollo de una red neuronal convolucional con la que se clasificaran tres tipos de imagenes por clase. El modelo debera aprender de los patrones y explicar el proceso para mejorar la generalización. 

# Propiedades del DataSet.
Nombre:rock_paper_scissors.  
Autor:Laurence Moroney 
Año: (2019)
Número de clases: 3 ('rock'[0], 'paper'[1], 'scissors'[2])
Set de entrenamiento: 2520 imágenes
Set de prueba: 372 imágenes.
Tamaño Imagenes: 300 * 300 * 3
